# LTP Ventas — ltpventas.com

Sitio estático de **LTP Ventas**, publicado con GitHub Pages en el dominio propio [ltpventas.com](https://ltpventas.com).

- `index.html`: página principal para seleccionar el sitio/tienda.
- `pinturasaleluis/`: acceso a la app de ventas de Pinturas Aleluis (Google Apps Script, embebida a pantalla completa).
- `logo.png`: logo del sitio.
- `CNAME`: indica a GitHub Pages que el dominio es `ltpventas.com`.

Los registros DNS del dominio (gestionados en Porkbun) apuntan a GitHub Pages para `ltpventas.com`.
